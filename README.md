# ProjectCollege
# 🎓 Информационная система колледжа (Сервис заказа справок и личный кабинет)

Веб-приложение для студентов и сотрудников учебной части колледжа. Система позволяет проходить авторизацию и регистрацию по ролям, подавать и отслеживать электронные заявки на получение справок, а администраторам — управлять статусами обращений через защищенную панель управления.

---

## 🚀 Основной функционал

### Для студентов:
- **Авторизация и Регистрация**: Безопасный вход с хэшированием паролей (Bcrypt) и сохранением сессии в `localStorage`.
- **Личный кабинет (`cabinet.html`)**: Просмотр данных профиля (ФИО, курс, группа, специальность, email).
- **Заказ справок (`services.html`)**: Удобная форма подачи заявок на получение документов с выбором способа получения и количества копий.
- **Интерактивный трекер**: Отслеживание статусов заявок («В обработке», «Одобрена», «Отклонена») с возможностью удаления обращений.

### Для администраторов (Учебная часть):
- **Защищенная панель управления (`admin.html`)**: Строгая проверка прав доступа на клиенте. Администраторы при входе перенаправляются прямо в панель управления.
- **Таблица заявок**: Полный обзор всех обращений студентов с привязкой к их группам и ФИО.
- **Управление статусами**: Мгновенное изменение статуса заявки (Одобрить / Отклонить) через PATCH-запросы на сервер.

---

## 🛠 Технологии и стек

- **Frontend**: HTML5, SCSS (методология БЕМ), JavaScript (ES6+, модульная архитектура).
- **Backend**: Node.js, Express.js (`server.js`).
- **База данных**: SQLite3 (`database.js`, `database.sqlite`) с автоматической миграцией и преднастроенным аккаунтом администратора.
- **Безопасность**: Bcrypt.js для хэширования паролей, CORS.
